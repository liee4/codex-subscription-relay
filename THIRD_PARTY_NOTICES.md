# Third-party project

This repository contains Windows setup and operation scripts for [CLIProxyAPI](https://github.com/router-for-me/CLIProxyAPI) by the CLIProxyAPI contributors. It uses the project's published Windows executable; the executable and upstream source code are **not** included in this repository.

CLIProxyAPI is available under the [MIT license](https://github.com/router-for-me/CLIProxyAPI/blob/main/LICENSE). See its repository for its source code, license, documentation, and release notes. The download script pins release `v8.0.59` and checks the archive's SHA-256 before use.

Remote access uses [Tailscale Funnel](https://tailscale.com/docs/features/tailscale-funnel). Tailscale itself is not included here.
